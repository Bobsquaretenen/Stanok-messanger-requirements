## 🚀 Основные возможности (Функционал)

Проект реализует три основные ролевые модели с индивидуальным набором прав (RBAC): **Администратор**, **Преподаватель** и **Студент**.

* **Аутентификация и безопасность:**
  * Вход для студентов осуществляется по номеру студенческого билета.
  * Вход для сотрудников (преподавателей/администраторов) — по уникальному текстовому логину.
  * Сессии защищены с помощью JWT-токенов.
* **Управление чатами:**
  * Создание групповых диалогов с привязкой к официальным учебным группам (например, «ИДБ-24-18»).
  * Режим модерации («Только для чтения»): преподаватель может запретить отправку сообщений студентами.
  * Глобальный поиск по чатам и удобная навигационная боковая панель.
* **Обмен сообщениями:**
  * Текстовые сообщения с визуальным разделением (входящие слева, исходящие справа).
  * Поддержка вложений (передача файлов размером до 50 МБ).
  * Запись и отправка голосовых сообщений.
* **Аудио- и видеокоммуникации:**
  * Встроенный модуль видео-чата (инициация возможна только преподавателем).
  * Голосовые вызовы непосредственно из интерфейса диалога.
* **Администрирование:**
  * Панель для управления пользователями и учебными группами.
  * Возможность парсинга/массового импорта данных студентов (ФИО, группы) из таблиц.

## 🛠 Технологический стек

**Backend (REST API & WebSockets):**
* **Java 17 / Spring Boot 3** — Основной фреймворк.
* **Spring Security + JWT** — Защита эндпоинтов и авторизация.
* **Spring Data JPA / Hibernate** — ORM для работы с базой данных.
* **STOMP / WebSockets** — Двунаправленный обмен сообщениями в реальном времени.

**Frontend (Web SPA):**
* **React.js / TypeScript** — Логика пользовательского интерфейса.
* **TailwindCSS / SCSS** — Адаптивная верстка и стилизация компонентов.
* **WebRTC / SFU** — Передача потокового видео и аудио с минимальной задержкой.
* **Axios** — HTTP-клиент для работы с REST API.

**База данных и Инфраструктура:**
* **PostgreSQL 15** — Основное реляционное хранилище.
* **Docker & Docker Compose** — Контейнеризация для унифицированного развертывания.
* **Nginx** — Reverse-proxy для маршрутизации запросов на проде.

## ⚡ Нефункциональные требования (Кратко)

* **Производительность:** Обработка 95% REST-запросов за время < 200 мс. Задержка WebSockets < 500 мс, WebRTC < 300 мс.
* **Масштабируемость:** Поддержка до 1000 одновременных активных подключений (CCU). Курсорная пагинация для оптимизации загрузки истории сообщений.
* **Безопасность:** Пароли хэшируются с помощью BCrypt (salt factor ≥ 10). Весь трафик передается по HTTPS / WSS (TLS 1.3).
* **Доступность (SLA):** 99.5% uptime в учебные часы с автоматическим переподключением сокетов на клиенте в случае обрывов сети.
* **Кроссбраузерность:** Поддержка Chrome, Яндекс.Браузер, Firefox, Safari, Edge. Адаптивность от 1024x768 до 1920x1080.
